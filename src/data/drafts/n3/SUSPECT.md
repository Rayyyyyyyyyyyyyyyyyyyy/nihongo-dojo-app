# 起草者沒把握的題目

全部 115 題都只經起草模型自己「不看答案作答」一次，這不算 Q12 的 G2（異廠模型盲解）或 G3（人工審閱）。下列題目在自檢時發現誘答在某種解讀下可能成立、語感不確定，或文法點等級有疑義，審閱時請優先看。

| ID | 理由 |
|---|---|
| g-n3-038 | 「今日中に届くところです」接受度不確定；起草者判斷不自然，但不是純文法錯誤。 |
| g-n3-045 | 「留学するうちに」通常不自然，但「辞書形＋うちに」有「做著做著」的用法，需母語者確認不成立。 |
| g-n3-061 | 「説明したわけだったが」起草者判斷不自然，未確認。 |
| g-n3-088 | 「時間こそなかった」在「こそ〜が」讓步句中可成立；本題無「が」，判斷為不自然，但界線細。 |
| g-n3-091 | 「親友にこそうそをつかれて」文法上可能成立，只是語意不自然。 |
| g-n3-117 | 「病気になったまま、健康の大切さが分かった」起草者判斷不自然，未確認。 |
| g-n3-128 | 「給料がいいおかげで休みが少ない」文法成立、語意不合；若審校者認為可作反諷，就是多解。 |
| g-n3-134 | 「絶対に満点を取っている」作未來狀態推測時接受度不確定。 |
| g-n3-141 | 使役被動：「先生に掃除をされた」「させた」都是合文法的句子，只靠「懲罰」語境排除，需確認語境夠強。 |
| g-n3-143 | 「お帰りしました」是錯誤敬語，但口語中常被誤用；若作為誘答是否太接近正解需判斷。 |
| g-n3-045、046、082、142–145 | 等級：〜ために／〜ため、たとえ〜ても、敬語基本形在部分清單屬 N4；SOURCES.md 說明文法點未逐項對照清單。 |
| 助詞類（g-n3-068–081、122、125–127） | 誘答多為「にとって／について／に対して」同一組，難度偏低、有「看形式就能猜」的風險；不是多解問題，是鑑別度問題。 |
